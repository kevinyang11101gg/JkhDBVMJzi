# 图书管理系统简介 python1244

## 项目概述

本图书管理系统基于Python和React的前后端分离架构，使用MySQL作为数据库存储，实现了用户管理与图书借阅管理的功能。

## 技术栈

### 开发环境
- 操作系统：Windows 10/11
- 开发工具：PyCharm 2023.1
- 数据库：MySQL 8.0
- Python版本：Python 3.8+

### 后端技术栈
- Web框架：Django 4.0
- 数据库ORM：Django ORM
- API开发：Django REST framework
- 权限管理：Django Auth

### 前端技术栈
- HTML5
- CSS3
- JavaScript
- Bootstrap 4
- jQuery

### 数据库工具
- MySQL Workbench
- Navicat Premium

## 功能模块

### 普通用户
- 登录与注册
- 个人信息管理（含密码更改）
- 座右铭发布与删除
- 图书搜索与查看
- 热门借阅与收藏
- 留言板互动（留言、回复、表情、图片、点赞）
- 图书借阅与归还
- 图书收藏与信息导出
- 用户画像与图书数据分析
- 个性化图书推荐

### 管理员用户
除了包含普通用户的所有功能外，还拥有以下权限：
- 留言板评论管理（置顶、删除）
- 图书归还信息审核
- 图书信息管理（新增、审核、编辑、删除）
- 用户信息管理（查看、编辑、删除）
- 用户收藏与借阅信息查看
- 收藏与借阅排行统计

### 其他
- 未登录路由保护
- 面包屑导航
- 丰富提示信息
- 图书信息预览
- 超期罚款与借书限制
- 登录滑块验证与安全锁定

## 核心亮点
- 基于Python+React+MySQL的稳健技术架构
- 前后端分离，易于维护与扩展
- 用户友好的界面与交互设计
- 精准的图书推荐系统
- 完善的权限与安全性管理
- 详尽的用户与图书数据分析功能
- 高效的数据库工具支持
